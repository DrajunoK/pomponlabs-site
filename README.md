# pomponlabs-site

Site web de **Pompon Labs** : page d'accueil qui liste toutes les applis disponibles.

Publié sur https://pomponlabs.com via GitHub Pages.

Ce dépôt ne contient que le site web (pas le code des applis).

## Contenu

- `index.html` : liste des applis (Botz, Popote)
- `style.css` : styles (clair/sombre)
- `logo.svg`, `logo.png` : mascotte Pompon
- `icon.svg`, `icon*.png`, `favicon.png`, `apple-touch-icon.png` : icônes
- `botz.png`, `popote.png` : icônes des applis
- `CNAME` : domaine `pomponlabs.com` (GitHub Pages)

## Ajouter une appli

Dupliquer un bloc `<a class="app">` dans `index.html` avec son lien, son icône et sa description.
